# Routes

## Web Areas

| Area | Purpose |
| --- | --- |
| Home | Platform overview, courses, challenges, and calls to action. |
| Course catalog | Public course browsing and course detail. |
| Challenge catalog | Public challenge browsing and challenge detail. |
| Account | Sign in, sign up, verification, recovery, and invitation onboarding. |
| Learning | Student dashboard, course content, quizzes, challenges, payments, and certificates. |
| Admin | Content, people, enrollment, payment, invitation, and analytics management. |

## API Areas

| Area | Purpose |
| --- | --- |
| Account | Account creation, sign in, profile, verification, recovery, and optional third-party sign-in. |
| Public content | Published courses, challenges, stats, and certificate verification. |
| Student courses | Enrollment, course entry, lesson/module progress, and quiz attempts. |
| Student challenges | Challenge listing, submissions, history, and completion. |
| Certificates | Student certificate listing and public certificate verification. |
| Admin courses | Course, module, lesson, quiz, block, and publishing management. |
| Admin challenges | Challenge creation, publishing, testing, and analytics. |
| Admin users | People management, invitations, imports, exports, and account state. |
| Analytics | Enrollment, retention, content, learner, and challenge reporting. |
| Payments | Payment creation, status, and admin payment views. |
