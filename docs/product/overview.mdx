# Product

## Purpose

WithinTech Learn helps program participants build practical skills through structured courses, quizzes, certificates, and coding challenges.

## Users

| User | Goal |
| --- | --- |
| Visitor | Browse courses, challenges, stats, and public pages. |
| Student | Enroll, learn, take quizzes, solve challenges, pay, and download certificates. |
| Admin | Manage content, users, enrollments, payments, analytics, and invitations. |

## Core Journey

1. Visitor signs up or accepts an invitation.
2. Student verifies the account and signs in.
3. Student browses courses or challenges.
4. Student enrolls or pays when required.
5. Student completes lessons, modules, quizzes, or code challenges.
6. Student earns progress, score, and certificates.
7. Admin monitors usage and improves content.

## Product Rules

- Courses can be drafted, published, or archived.
- Course access can be free, paid for course access, or paid for certificate access.
- Quizzes can live at course, module, or lesson level.
- Certificates are unique per student and course.
- Challenges can use visible and hidden tests.
- Admin actions require elevated permissions.
