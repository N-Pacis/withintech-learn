# Workflows

## Student Enrollment

1. Student signs up, verifies the account, or accepts an invitation.
2. Student opens a published course.
3. Free courses can be enrolled directly.
4. Paid courses go through checkout.
5. The platform creates or updates the enrollment.
6. The student enters the learning area.

## Course Completion

1. Student reads module and lesson content.
2. Progress is recorded as required content is completed.
3. Course quiz becomes available when required content is complete.
4. Passing quiz updates progress and can create certificate eligibility.
5. Certificate record is unique per user and course.

## Challenge Submission

1. Student opens a published coding challenge.
2. Student submits language and code.
3. The platform loads the challenge definition and tests.
4. Code runs through the isolated execution layer.
5. The platform stores the submission result.
6. Accepted submissions update challenge progress and score.

## Admin Content Publishing

1. Admin creates a course in draft.
2. Admin adds modules, lessons, content blocks, and quizzes.
3. Admin uploads media when content needs it.
4. Admin publishes the course.
5. Public and student course lists can show the course.

## Student Import

1. Admin uploads a supported spreadsheet.
2. The platform validates size, format, and required fields.
3. The platform creates eligible students.
4. The import report shows created, skipped, and failed rows.

## Payment

1. Student starts checkout from the learning flow.
2. The platform creates a payment record.
3. Student completes the provider flow.
4. The platform checks payment status.
5. Paid course access or certificate access is unlocked.
