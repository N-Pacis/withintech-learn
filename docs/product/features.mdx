# Features

## Public

- Landing page with courses, challenges, stats, partners, and calls to action.
- Public course and challenge listing pages.
- Public course and challenge detail pages.
- Certificate verification page.

## Account

- Sign up and sign in.
- Email verification.
- Password recovery.
- Optional third-party sign-in.
- Invitation acceptance for invited users.

## Student

- Course browsing and enrollment.
- Module and lesson learning.
- Text, image, and code content blocks.
- Course, module, and lesson quizzes.
- Quiz attempts, pass/fail status, and progress.
- Coding challenge workspace.
- Submission history and test results.
- Certificates and downloadable certificate view.
- Payments for course or certificate access.

## Admin

- Dashboard analytics.
- Course, module, lesson, quiz, and content block management.
- Challenge creation and publishing.
- User, enrollment, invitation, and payment management.
- Leaderboards and challenge stats.

## Platform

- External media storage.
- Email templates.
- Cached public reads.
- Error monitoring.
- API documentation available through approved access.
