# Design System

## Personality

The product should feel focused, modern, and practical. It is a learning tool, not a marketing brochure. Pages should help users scan, decide, and act.

## Tokens

| Token | Value | Use |
| --- | --- | --- |
| Background | `#ffffff` | Main page background. |
| Foreground | `#0f0f0f` | Primary text. |
| Surface | `#fafafa` | Shells and quiet sections. |
| Card | `#ffffff` | Cards and panels. |
| Border | `#e5e7eb` | Default dividers. |
| Primary | `#3d006b` | Main actions and active states. |
| Primary dark | `#2a004a` | Hover and emphasis. |
| Primary soft | `#f3e8ff` | Subtle active backgrounds. |
| Accent | `#f97316` | Highlights and secondary emphasis. |
| Success | `#10b981` | Positive status. |
| Warning | `#f59e0b` | Attention status. |
| Danger | `#ef4444` | Destructive status. |

## Typography

| Role | Font |
| --- | --- |
| Headings | Syne, weight 700+ |
| Body | DM Sans, medium-light rhythm |
| Labels | DM Sans, medium, compact |

## Components

| Component | Style |
| --- | --- |
| Buttons | Inline flex, medium weight, 6px radius, primary/secondary/ghost/danger variants. |
| Cards | White surface, border, small shadow only when needed. |
| Badges | Uppercase, compact, rounded, high contrast. |
| Tables | Clear headers, restrained borders, dense spacing. |
| Forms | Reusable inputs, selects, textareas, file upload, validation messages. |
| Editors | CodeMirror for code, Tiptap for rich lesson/challenge content. |
