# Features

## Public

- Landing page with courses, challenges, stats, partners, and calls to action.
- Public course and challenge listing pages.
- Public course and challenge detail pages.
- Certificate verification page.

## Auth

- Sign up and sign in.
- Email verification with OTP.
- Password reset.
- Google auth support.
- Admin invitations and invitation acceptance.

## Student

- Course browsing and enrollment.
- Module and lesson learning.
- Text, image, and code content blocks.
- Course, module, and lesson quizzes.
- Quiz attempts, pass/fail status, and progress.
- Coding challenge workspace with CodeMirror.
- Submission history and test results.
- Certificates and downloadable certificate view.
- Payments for course access or certificates.

## Admin

- Dashboard analytics.
- Course, module, lesson, quiz, and block management.
- Challenge creation with starter code, parameters, return type, and test cases.
- User, admin, student, enrollment, invitation, and payment management.
- Leaderboards and challenge stats.

## Platform

- S3-compatible file storage.
- SMTP email templates.
- Redis-backed cache helpers.
- Sentry instrumentation.
- Swagger API docs at `/docs`.
- Health checks at `/health` and `/health/full`.
